# Brand fonts for generated images

TrueType copies of the farm's brand typefaces, used server-side by GD/Imagick to draw text
on generated social images (Pinterest 1000 × 1500 JPEGs). The public website still loads its
web fonts separately; these files are not served to visitors (`includes/` is not web-browsable).

| File | Typeface | Role | Copyright |
| --- | --- | --- | --- |
| `YoungSerif-Regular.ttf` | Young Serif | Headings | 2023 The Young Serif Project Authors |
| `Lora-Regular.ttf` | Lora | Body | 2011 The Lora Project Authors (Reserved Font Name "Lora") |
| `Lora-Bold.ttf` | Lora Bold | Body emphasis | 2011 The Lora Project Authors (Reserved Font Name "Lora") |
| `NothingYouCouldDo-Regular.ttf` | Nothing You Could Do | Script accent | 2010 Kimberly Geswein |

All four are licensed under the SIL Open Font License, Version 1.1 (https://openfontlicense.org).
The copyright and license notice is also embedded in each file's name table. Files downloaded
from Google Fonts and uploaded Nov 5, 2026; System Health → Image tools checks they are present.
